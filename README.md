# Adamjee Life Website Clone

A frontend website clone inspired by the official Adamjee Life website, developed from scratch using **HTML, CSS, and JavaScript**.

This project was created as a frontend development practice project to improve my skills in website layout, responsive design, styling, and JavaScript interactions.

---

## 🌐 Project Reference

This project is inspired by the following website:

**Adamjee Life:**  
https://www.adamjeelife.com/

> This is an educational and frontend practice project and is not affiliated with or endorsed by Adamjee Life.

---

## 📖 About The Project

The Adamjee Life Website Clone is a static frontend implementation designed to recreate the look and feel of a professional insurance and financial services website.

The website was developed without using frontend frameworks such as React, Vue, or Angular.

The main focus of this project was to practice:

- Semantic HTML structure
- Modern CSS styling
- Responsive web design
- JavaScript functionality
- Website layout development
- Navigation and UI components
- Reusable styling
- Project file organization

---
